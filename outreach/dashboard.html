Want this to auto-update without re-downloading? (optional)

You can point this dashboard at a live, published version of your sheet:

  1. In Google Sheets: File ▸ Share ▸ Publish to web ▸ pick the Contacted sheet ▸ format CSV ▸ Publish. Copy the link it gives you.
  2. Open dashboard.html in a text editor, find the line near the bottom that says const PUBLISHED_CSV_URL = ""; and paste your link between the quotes.
  3. Save and reopen the dashboard — it will fetch live data and the ↻ Reload button will refresh it.

Note: "Publish to web" makes that one sheet readable by anyone with the link. Your contact data lives there, so only do this if you're comfortable with that.
